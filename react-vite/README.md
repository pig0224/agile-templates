# {{name}}

React 19 + Vite + TypeScript 项目，由 `agile init project --template react-vite` 生成。

## 开发

```bash
npm install
npm run dev      # 本地开发服务器
npm run build    # 构建
npm test         # vitest 单元测试
npx playwright install chromium   # 首次执行 e2e 前安装浏览器
npm run e2e      # Playwright e2e（固化脚本在 e2e/；运行产物不提交）
```
